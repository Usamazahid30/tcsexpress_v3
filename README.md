# TCS — Courier, Logistics & E-Commerce Delivery

A modern, high-performance web portal for Pakistan's leading express courier, logistics, and e-commerce delivery network.

## Features

- **Shipment Tracking**: Real-time package tracking with interactive status feedback.
- **Service Showcase**: Interactive smooth carousel showcasing TCS Air, Logistics, Sentiments, E-Com Solutions, International Express, TCS Studio, and Red Box.
- **Modern Design & Micro-interactions**: Built with Tailwind CSS v4, dynamic oklch themes, glassmorphism, responsive navigation, and Framer Motion animations.
- **Responsive Layout**: Designed for seamless experience across mobile, tablet, and desktop viewports.

## Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) + `tw-animate-css`
- **Animations**: [Motion (Framer Motion)](https://motion.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Component UI**: Radix UI Primitives & Shadcn UI

## Getting Started

### Prerequisites

- Node.js (version 18+ recommended)
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
